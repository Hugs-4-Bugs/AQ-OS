# AcquisitionOS Brand Assets

These files were assembled from the approved logo reference image and the standalone symbol shown in the conversation.

## Included
- 01: Primary horizontal logo for light backgrounds (transparent PNG)
- 02: Standalone brand symbol (transparent PNG)
- 03: Horizontal logo for dark backgrounds (transparent PNG)
- 04: Monochrome black horizontal logo (transparent PNG)
- 05–06: Dark and light app icons (1024×1024)
- 07–09: Favicon PNG sizes, ICO and SVG wrapper
- 10: Apple Touch Icon (180×180)
- 11–12: Android/PWA icons (192×192 and 512×512)
- 13: Social/profile avatar (512×512)
- 14: Open Graph/social sharing image (1200×630)

## Important production notes
- The logo and symbol are raster PNGs reconstructed/cropped from the approved generated brand-board reference. They are not original editable vector master artwork.
- `09-favicon.svg` is an SVG container with the approved PNG embedded; it is not a fully vector-traced logo.
- For production, request a true vector master (editable SVG/AI/PDF paths) from a designer if exact scalable vector geometry is required.
- Check the PNGs against your actual header/footer backgrounds before deployment. No email, authentication, DNS or application configuration is included.
