# Glossary — AcquisitionOS

> Owner: Engineering + Product. Status: Living document. Last reviewed: 2026-09-09.
> Definitions of all domain terms, abbreviations, and technical terms used in the codebase + the docs.

## A

**AcquisitionOS** — the product. An AI-powered B2B client-acquisition platform (Next.js + Prisma + Stripe + Z-AI).

**ADR** — Architecture Decision Record. See `docs/technical/ARCHITECTURE-DECISION-RECORDS.md`.

**AI Copilot** — the in-app AI chat assistant (`/api/ai/chat`, `src/components/dashboard/assistant-tab.tsx`). Distinguished from "autonomous outreach" (which sends without the user in the loop).

**App Router** — Next.js 13+ routing convention (vs the old Pages Router). The project uses App Router throughout.

**ARPU** — Average Revenue Per User. MRR / paying users.

**AuditLog** — append-only Prisma model recording security-relevant actions (login, MFA change, key rotation, payment, data export).

**Auth gate** — the client-side component that shows the sign-in / sign-up UI when the user is unauthenticated, and the dashboard when authenticated (`src/components/dashboard/auth-gate.tsx`).

## B

**Backfill** — data written to fill a column added as NOT NULL to existing rows. Required before a destructive migration.

**BCC** — Blind Carbon Copy. The outreach send BCCs the user (sender) so they have a copy. See [DATA-FLOW-DIAGRAMS.md](../technical/DATA-FLOW-DIAGRAMS.md) §3.

**Blueprint** — a workflow template. See `WorkflowTemplate` model.

**BullMQ** — a Redis-backed job queue (planned, ADR-011). Not yet shipped.

## C

**CAN-SPAM** — the US law governing cold outreach email. Requires a postal address + unsubscribe link + clear subject. The user is responsible; we provide templates.

**Chat session** — an AI conversation in the Assistant tab (`AiChatSession` + `AiChatMessage`).

**Cohort** — a group of users sharing a sign-up period; used in retention analytics.

**Conference data** — the Google Calendar payload that requests a Meet link generation (`conferenceData.createRequest.conferenceSolutionKey.type = 'hangoutsMeet'`).

**Conversation** — a cross-channel thread with a lead (`Conversation` + `ConversationMessage`). Distinct from `Communication` (the outreach/reply log).

**Conversion score** — AI's estimate of how likely a lead is to convert (become a paying customer). One of the four AI scores.

**CORS** — Cross-Origin Resource Sharing. `src/lib/security/cors-config.ts` locks it to the app's origin.

**Credits** — the metering unit for AI-heavy actions. Each plan grants a monthly allowance; overage requires an add-on pack.

**CreditsLedger** — append-only Prisma model recording every credit in/out + the balance after.

**CRON_SECRET** — the Bearer token required by `/api/cron/*` endpoints. Stored in `.env`.

**CSRF** — Cross-Site Request Forgery. Defence: SameSite=strict cookies + OAuth `state` parameter.

**CSE** — Google Custom Search Engine. Powers lead discovery. `$5/1k queries`.

## D

**DPA** — Data Processing Addendum. Needed with each sub-processor (Stripe, Google, Z-AI, Resend, Sentry, hosting).

**DPDP Act** — Digital Personal Data Protection Act, 2023 (India). The Indian data-protection law.

**DSAR** — Data Subject Access Request (GDPR) / Data Principal Access Request (DPDP). The user's right to access / export their data. Implemented via `/api/settings/account/export-request`.

**Dual auth** — authentication via session cookie OR API key (`withDualAuth` in `src/lib/auth-middleware.ts`).

**Dunning** — payment-recovery email flow for past-due subscriptions. `src/lib/payment-recovery-service.ts`.

## E

**Edge Runtime** — Next.js's V8-based runtime (vs Node.js). Some files (`instrumentation.ts`) trip warnings because they use Node.js modules (`fs`, `path`).

**Elite** — the top pricing tier (~$99/mo; 2,000 credits/mo; 10 team seats; 2,000 API req/hr).

**EmailAccount** — Prisma model storing a user's connected Gmail (OAuth) credentials (encrypted).

**EmailBounce** — Prisma model recording a bounced email (permanent / transient).

**EmailUnsubscribe** — Prisma model of unsubscribed emails; the outreach send checks this before sending.

**Entitlement** — a permission / limit granted by a plan (`src/lib/entitlement-service.ts`, `src/lib/plan-gates.ts`).

## F

**FAB** — Floating Action Button. The `+`, feedback, and AI-chat-bubble buttons in the bottom-right corner.

**FC** — (Aliyun) Function Compute. The sandbox's underlying platform.

**Feature flag** — `FeatureFlag` Prisma model; admin-controlled on/off for features.

**Free** — the $0 pricing tier (50 credits/mo; no API; no autonomous mode).

**freeBusy** — Google Calendar API that returns busy time ranges for a given time window. Used for availability checks.

## G

**GDPR** — General Data Protection Regulation (EU). The European data-protection law.

**Google Meet link** — generated by the Calendar events.insert with `conferenceData`. Extracted from `event.hangoutLink`.

**GST** — Goods and Services Tax (India). `src/lib/gst-service.ts` + `src/lib/tax-service.ts` compute it for Indian invoices.

## H

**HMAC** — Hash-based Message Authentication Code. Used for webhook signatures (Stripe, Google Pub/Sub).

**hangoutLink** — the Google Meet URL in a Calendar event response.

**Hot lead** — a lead flagged as "hot" by the hot-lead-detection service (recency + score + intent signals).

## I

**IDOR** — Insecure Direct Object Reference. Defended by `userId` filtering on every query.

**Instrumentation** — Next.js's hook for code that runs at server startup (`src/instrumentation.ts`). Used for env validation + Sentry init.

## J

**JWT** — JSON Web Token. HS256-signed; `access_token` (15 min) + `refresh_token` (30 days). Stored in httpOnly cookies.

## K

**KnownDevice** — Prisma model of a user's recognised devices (fingerprint + UA + IP + trusted).

## L

**Lead** — a prospect business discovered / imported by a user. The core entity of the product.

**LeadActivity** — the timeline of actions taken on a lead (email sent, replied, meeting booked, stage changed).

**LeadScore** — AI's four scores (reply, conversion, urgency, revenue potential) + written reasoning.

**LCP** — Largest Contentful Paint. A Core Web Vital.

**LTV** — Lifetime Value. The total revenue from a user over their lifetime.

## M

**Magic link** — a one-time, 15-min-TTL sign-in link emailed to the user. Click → session.

**MFA** — Multi-Factor Authentication. TOTP with backup codes.

**MRR** — Monthly Recurring Revenue.

**Meet link** — see Google Meet link.

**Meeting orchestration** — the engine that proposes slots, books meetings, generates Meet links, sends reminders + prep + follow-ups. `src/lib/meeting-orchestration-service.ts`.

## N

**NextAuth** — Next.js's auth library (v4 available; the project uses a custom JWT auth instead — ADR-004).

**N+1 query** — a list query that triggers N additional queries (one per row) to load relations. Defended by Prisma's `include`.

## O

**OAuth** — the Google sign-in + Gmail + Calendar integration auth flow.

**OIDC** — OpenID Connect. Google's OAuth 2.0 flow includes OIDC profile claims.

**OrgMember** — Prisma model of a user's membership in an Organization (with role: owner/admin/member/viewer).

**OTP** — One-Time Password. Used for email verification, login (passwordless), password reset.

**OutreachMessage** — Prisma model of a generated outreach email (subject, body, status: draft/sent/failed).

**OutreachSequence** — a multi-step campaign (Day 0 email → Day 3 follow-up → Day 7 LinkedIn).

## P

**Persona** — a fictional user representing a target segment. See `docs/product/USER-PERSONAS.md`.

**PII** — Personally Identifiable Information. Lead emails + phones + business names + user account data.

**Plan gate** — `src/lib/plan-gates.ts`; enforces plan limits (credits, leads/mo, API rate, seats).

**Platform adapter** — `src/lib/meetings/platform-adapter.ts`; abstracts Google Meet / Zoom / Teams / Calendly. Zoom/Teams/Calendly are stubs.

**Pro** — the middle pricing tier (~$29/mo; 500 credits/mo; 1 team seat; 50 API req/hr).

**Prisma** — the ORM. SQLite now; PostgreSQL target.

**Proxy** — `src/proxy.ts` (Next 16's middleware). Replaces `middleware.ts`.

**Pub/Sub** — Google's push-notification system for Gmail inbox changes. `src/app/api/gmail/pubsub/`.

## R

**RAG** — Retrieval-Augmented Generation. The user ingests URLs / text / CSV; the AI retrieves relevant chunks for context. `/api/ai/rag/*`.

**Rate limit** — per-IP (auth, 5/min) or per-API-key (Free 50/hr, Pro 500/hr, Elite 2000/hr). `src/lib/security/rate-limiter.ts`.

**Razorpay** — the Indian payment provider. `src/lib/razorpay-service.ts`.

**ReplyScore** — AI's estimate of how likely a lead is to reply to outreach. One of the four AI scores.

**Resend** — an email provider (optional primary; preferred over SMTP if configured). `src/lib/email.ts`.

**Retention** — (1) the data-retention policy (`src/lib/compliance/retention.ts`); (2) the user-retention metric (1 - churn).

**Reveal key dialog** — the one-time modal showing a newly created / rotated API key. Has `onPointerDownOutside` preventDefault (no outside-click close).

**RBAC** — Role-Based Access Control. `src/lib/rbac.ts`.

**RFP** — Request for Proposal. (Not in the codebase; common B2B term.)

## S

**SaaS** — Software as a Service. AcquisitionOS's business model.

**SameSite** — the cookie attribute preventing CSRF. The auth cookies are `SameSite=strict`.

**Sandbox** — the restricted cloud environment the dev server runs in (Aliyun FC / GLM platform). Periodically wipes `.env` + kills the server.

**SDR** — Sales Development Representative. The "autonomous SDR pipeline" (`/api/cron/sdr-cycle`) automates the role.

**SEV-1/2/3/4** — severity levels. SEV-1 = critical (page now); SEV-4 = low (next release). See [INCIDENT-RESPONSE-PLAN.md](../security/INCIDENT-RESPONSE-PLAN.md).

**Sequence** — see OutreachSequence.

**Session** — a user's authenticated session. `UserSession` table; `refresh_token` cookie.

**Shadcn/ui** — the component library (Radix + Tailwind, copy-paste, owned by us). `src/components/ui/`.

**SOC 2** — a security + availability compliance certification. On the roadmap.

**SSRF** — Server-Side Request Forgery. The website scraper is the main surface; an SSRF allowlist is a P0 gap.

**Stripe** — the primary payment provider. `src/lib/stripe-service.ts`, `src/lib/payment-service.ts`.

**SWC** — the Next.js compiler's native binary. The sandbox sometimes removes it; `keepalive-v2.sh` restores it.

## T

**TanStack Query** — the server-state library (React Query). Used for fetching + caching + polling.

**Telegram** — a notification channel. `src/lib/telegram-service.ts`.

**Tenant** — a user / organization. Multi-tenancy is via `userId` / `orgId` on every data row.

**TOTP** — Time-based One-Time Password. MFA method.

**Trial** — the 14-day free trial of Pro on signup.

**Twilio** — the WhatsApp Business API provider. `src/lib/whatsapp-service.ts`.

## U

**UrgencyScore** — AI's estimate of how urgently the lead needs the service. One of the four AI scores.

**UserSession** — Prisma model of a refresh-token record (for revocation).

**UserSettings** — Prisma model of a user's app + meeting preferences.

## V

**Vector search** — semantic search over RAG documents. `/api/ai/vector-search`.

**Vercel** — a deployment platform. One of the supported targets.

## W

**Webhook** — an HTTP endpoint called by an external service (Stripe, Google Pub/Sub). Inbound = they call us; Outbound (planned) = we call the user's endpoint.

**White-label** — the feature letting agencies run AcquisitionOS under their own brand. Half-built (`src/lib/white-label-service.ts`, `src/lib/org-branding-service.ts`).

**Workflow** — an automation blueprint. `WorkflowDefinition` + `WorkflowExecution`. The Workflow Builder is `src/components/dashboard/workflow-builder.tsx`.

## X

**XTransformPort** — the gateway query parameter for routing to a different port (for mini-services). E.g. `/api/test?XTransformPort=3030`.

## Y, Z

**Z-AI** — the AI provider (chat + embeddings). Used backend-only (ADR-006).

**Zustand** — the client-state library. `src/lib/store.ts`.
