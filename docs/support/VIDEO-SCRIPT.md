## 4. Voiceover & Music Direction

**Voice profile:**

- Mid-range, warm, confident. Think "experienced founder telling a friend about their secret weapon" — not a radio ad read.
- Smile on the Won-stage line ("that feeling never gets old") — it should sound genuinely delighted.
- Punch the verbs: *finds, scores, writes, tracks.*

**Music:**

- Modern, minimal electronic; 95–110 BPM.
- Duck −8 dB under narration, swell +2 dB in the 2-second gaps between scenes.
- Hard resolve at 4:50 for the CTA.

**Sound design:**

- Soft UI clicks on cursor actions (subtle — under −20 dB).
- One "success" chime on Save to Leads and on drag to Won. Nowhere else.
- No whooshes — they date the video.

**Pacing rules:**

- Max 3 cuts per 10 seconds. This is a product demo, not a hype reel.
- Any screen the narrator mentions must be visible within 2 seconds of the mention.
- Never narrate over a loading spinner longer than 3 seconds — cut to a pre-captured result state.

## 8. Pre-Recording Checklist

Complete every item before hitting record — re-records cost more than prep.

### Demo environment

- [ ] Fresh demo account seeded: ~40 realistic leads across 3 niches, 2 countries (no real business data)
- [ ] Pipeline pre-populated: deals in Replied, Discussion, and Proposal stages so drags look natural
- [ ] Google Calendar connected with realistic busy/free blocks for the slot picker scene
- [ ] Gmail test inbox ready to receive the confirmation-copy split-screen
- [ ] Browser at 1920×1080, 100% zoom, bookmarks bar hidden, notifications silenced
- [ ] Demo account name/branding generic ("Demo Agency") — no personal names

### Capture setup

- [ ] Screen recorder at 1080p/60fps; cursor highlight enabled
- [ ] Mouse speed set to slow/normal — fast cursors feel frantic on playback
- [ ] Clean close all other tabs and apps; disable OS notifications
- [ ] Record each scene as a separate file (simpler re-takes)

### Voiceover

- [ ] Script rehearsed aloud twice; timings verified against the timing-check table
- [ ] Record in a treated room; target −16 LUFS integrated
- [ ] Record full takes, then pick best sentences — never edit mid-sentence
